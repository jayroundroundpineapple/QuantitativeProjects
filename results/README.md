# 实测产物归档

这里放的是**能对着核对的原始数据**，不是结论摘要。结论在 [`../docs/实测记录.md`](../docs/实测记录.md)，
指标读法在 [`../README.md`](../README.md) 第四节。

每一组都是同一台机器、同一份缓存、同一套代码跑出来的，参数写在各自的 `metrics.json` 里。
文件含义：

| 文件 | 内容 |
|---|---|
| `metrics.json` | 本次全部参数 + 每条策略的完整指标 + 诊断项 + 前 10 名选股 |
| `nav.csv` | 逐日净值（组合 / 基准）与回撤 |
| `trades.csv` | 每一笔买卖：日期、代码、方向、股数、成交价、费用 |
| `holdings.csv` | 每个调仓日的持仓明细与权重 |
| `ranking.csv` | 最后一个交易日全部股票的总分、四个因子百分位、是否入选 |
| `stress.csv` | 压力测试每次抽样的年化 / 超额 / 回撤 |
| `report_*.html` | 完整 HTML 报告（下载后用浏览器打开） |

## 五组产物

| 目录 | 配置 | 多因子年化 | 用来证明什么 |
|---|---|---|---|
| `A-四因子-both-100只/` | 四因子 · both · 97 随机 + 电网 3 只 · seed 42 | **7.12%** | 主结果 |
| `B-两因子-both-100只/` | 只价值+动量 · 同上同一个池 | **11.06%** | 与 A 同池对照 → 财报因子影响 -3.94pp |
| `C-四因子-factor-100只/` | 四因子 · factor · 纯 100 随机 · seed 42 | **4.08%** | 与 D 同池对照 |
| `D-两因子-factor-100只/` | 只价值+动量 · 纯 100 随机 | **4.37%** | 与 C 对照 → 财报因子影响 -0.29pp |
| `E-压力测试-400母体/` | 四因子 · 400 只母体抽 100 只 × 12 次 | 中位 **+1.85%** | 单次回测的运气有多大 |

**A 对 B、C 对 D 是各自严格同池的**（股票池、种子、区间、成本全同，只有 `fundamentals` 不同）。
**但 A/B 与 C/D 之间不能互相比较**——前者的池里有那三只电网股，后者是纯随机，
两因子下差 6.7 个百分点。这个对比本身就是结论之一。

## 复现

```bash
# 在仓库根目录
python3 app/server.py --port 8770 --no-open

curl -X POST localhost:8770/api/run -H 'Content-Type: application/json' -d \
 '{"pool":"sample","n":100,"start":"2021-01-01","end":"2026-11-16","top":20,
   "mode":"both","seed":42,"cost":true,"use_cache":true,"fundamentals":false}'
# → 应得到 11.06% / 25.89%，与 B 一致

# 再归档
python3 tools/collect_results.py <job_id> "B-两因子-both-100只"
```

⚠️ 复现有前提：**同一份本地缓存**。行情和财报缓存不同（比如换了一天重新抓），
数字会有小数点后的漂移。缓存目录 `data/cache/` 不入库，但重新抓取是幂等的。

⚠️ 数据源是免费的腾讯行情 + 百度估值 + 东财财报，**只含当前存续的股票**。
所有收益都系统性偏高，偏高多少见 `docs/实测记录.md` 第 5 节。
