# 量化工具盘点（2026-11 实测口径）

按"你要干什么"分类，每一类给一句实话。

---

## 1. 数据源：整个量化里唯一必须花钱的地方

| 工具 | 价格 | 含退市股 | 数据质量 | 适合 |
|---|---|---|---|---|
| **akshare** | 免费 | ❌ | 免费里最好，但接口常改名、常限流 | 学习、练手、原型 |
| **tushare pro** | 积分制，200–2000 元/年 | 部分 | 稳定，财务数据规整 | **个人首选** |
| **baostock** | 免费 | ❌ | 很稳但更新慢，无财务明细 | 教学 |
| **efinance / adata** | 免费 | ❌ | 社区维护，接口易断 | 备用源 |
| **聚宽 JQData** | 约 3000–10000 元/年 | ✅ | 干净，有因子库 | 认真做策略 |
| **米筐 RQData** | 约 5000–20000 元/年 | ✅ | 质量高，含 tick | 中高频 |
| **Wind / 聚源** | 2–10 万/年 | ✅ | 机构标准 | 机构、产品 |

**实话：免费数据只能验证"代码写得对不对"，不能验证"策略行不行"。** 存活偏差 0.5–4 个百分点/年，足以把亏损策略做成盈利策略。

> 省钱方案：tushare pro（几百元）+ 自己从交易所公告补退市名单。

## 2. 回测框架：先看你是"写代码"还是"点鼠标"

| 工具 | 类型 | 语言 | 优点 | 缺点 |
|---|---|---|---|---|
| **聚宽 / 米筐 / 优矿** | 在线平台 | Python | 数据+回测+实盘一体，开箱即用 | 锁定平台，导出困难 |
| **Backtrader** | 本地库 | Python | 事件驱动、贴近实盘、社区大 | 代码啰嗦，性能一般 |
| **vectorbt** | 本地库 | Python | 向量化，**快 100 倍**，适合参数扫描 | 学习曲线陡，内存吃紧 |
| **bt** | 本地库 | Python | 组合再平衡写起来最舒服 | 只适合低频 |
| **qlib（微软）** | 本地框架 | Python | 内置 Alpha158/360 因子库、模型流水线 | 重，依赖多，文档偏学术 |
| **rqalpha** | 本地框架 | Python | 米筐开源版，A股规则完整 | 社区活跃度下降 |
| **Zipline-reloaded** | 本地库 | Python | 老牌，Quantopian 遗产 | 数据接入麻烦 |
| **本仓库** | 最小实现 | Python | 700 行，能读懂每一行，涨跌停/成本都处理了 | 无行业中性、无组合优化 |

**建议路径**：本仓库读懂 → 聚宽/米筐验证 → 需要极致速度再上 vectorbt。

**不要一上来就用 qlib**：它很强，但你会花两周调环境、两周读文档，然后发现自己连"为什么亏"都说不清。

## 4. 实盘接口

| 工具 | 通道 | 门槛 | 说明 |
|---|---|---|---|
| **QMT / Ptrade** | 券商提供 | 通常 50 万资产 | **A股程序化交易的正路**，合规、稳定 |
| **掘金量化** | 券商 + 自研 | 免费起 | 支持模拟盘，文档好 |
| **vnpy** | 开源 | 需自己接柜台 | 期货 CTF 首选，股票很折腾 |
| **easytrader** | 模拟点击客户端 | 免费 | 灰色地带，**不建议**上真钱 |
| **聚宽/米筐实盘** | 平台托管 | 订阅费 | 省事，但策略在别人服务器上 |

**实话：个人做 A 股程序化，唯一合规且稳定的路是券商 QMT/Ptrade。** 其他的要么违规，要么随时失效。

## 5. 数据存储

| 工具 | 用途 |
|---|---|
| **parquet** | 列式存储，比 CSV 快 10 倍、小 5 倍，**默认选它** |
| **duckdb** | 单机 SQL 引擎，直接查 parquet，零部署 |
| **clickhouse** | 千万级以上 tick 才需要 |
| **sqlite** | 小数据够用，但并发差 |

本仓库用 `pkl` 缓存只是图省事，**正式项目换 parquet**。

## 6. 如果你只想投 ETF，需不需要量化

不需要复杂框架。你需要的只有两件事：

1. **一个再平衡规则**（季度、阈值、风险平价三选一）
2. **一个估值分位表**（沪深300 / 中证500 / 创业板 PE、PB 分位）

用 Excel 就能做，而且**比大多数 Python 策略更不容易亏钱**，因为交易频率低、成本低、不依赖数据质量。
