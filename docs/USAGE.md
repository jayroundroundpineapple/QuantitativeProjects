# 使用说明

## 0. 最简单的用法：双击，不碰终端

打开 Finder，进入 `quant_lab` 目录，双击 **`量化工作台.app`**。
浏览器会自动打开 `http://127.0.0.1:8770/`，左边设参数，点「开始回测」。

界面分区：

| 位置 | 内容 |
|---|---|
| 左侧栏 | 股票池（随机 / 电网三只 / 自定义代码）、区间、持仓数、阈值、成本开关、初始资金 |
| 概览 | 12 个核心指标卡 + 净值曲线 + 回撤曲线 |
| 策略对比 | 多因子 / 轮动 / 纯持板块 三条曲线叠加 + 指标对照表 |
| 分年度 | 年度柱状图 + 明细表 |
| 持仓与交易 | 期末持仓、交易笔数、CSV 下载、完整 HTML 报告 |
| 诊断 | 轮动强度分曲线 + 「这组数字哪里会骗你」 |
| 怎么用 | 指标读法、每周流程、作废条件 |

关掉这个应用即停止服务。产物在 `out/jobs/<任务ID>/`（`state.json`、`report_*.html`、`trades.csv`、`holdings.csv`、`nav.csv`）。
右上角「打开产出目录」直接在 Finder 里定位。

**打不开怎么办**

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击提示「无法打开，来自身份不明的开发者」 | Gatekeeper | 右键 → 打开 → 仍要打开（只需一次） |
| 弹窗说找不到 Python 环境 | 系统 Python 缺 pandas | 用 `启动量化工作台.command` 看具体报错，或 `pip install pandas numpy akshare` |
| 浏览器没自动弹出 | 默认浏览器被改 | 手动访问 `http://127.0.0.1:8770/` |
| 页面一直停在 14% | 正在抓行情（约 0.45 秒/只） | 等；进度条会逐只推进 |

## 1. 四个入口，各管什么

| 命令                            | 数据          | 用途                                   |
| ----------------------------- | ----------- | ------------------------------------ |
| `run.py --demo`               | 合成数据        | **先跑这个**。数据里埋了已知有效的因子，跑不出超额就是代码有 bug |
| `run.py --csv data`           | 本地 CSV      | 接你自己的数据（付费源导出的）                      |
| `run_real.py --n 100`         | akshare 实时抓 | 真实 A 股，暴露真实缺陷（存活偏差、限流）               |
| `run_real.py --mode rotation` | akshare     | 只跑电网设备行业轮动                           |

常用参数：

```bash
python3 run.py --demo --top 30              # 持仓从 20 只改成 30 只
python3 run_real.py --n 100 --start 20230101 --end 20261115
python3 run_real.py --n 100 --mode factor   # 只跑多因子，不跑轮动
```

## 2. 每个数字怎么读

| 指标        | 含义               | 及格线        | 说明                      |
| --------- | ---------------- | ---------- | ----------------------- |
| **年化收益**  | 复利年化             | —          | 必须和基准一起看，单看没意义          |
| **年化超额**  | 策略 - 等权基准        | > 5%       | 低于 3% 不值得承担主动风险         |
| **年化波动**  | 收益标准差            | —          | A股多因子策略通常 20–30%        |
| **夏普**    | 年化收益 / 波动        | > 0.5      | 无风险利率按 0 算，所以偏乐观        |
| **最大回撤**  | 峰值到谷底            | < 基准 × 1.5 | 超过说明超额是靠加杠杆/加集中度换的      |
| **卡玛**    | 年化 / 最大回撤        | > 0.5      | 衡量"每单位痛苦换多少收益"          |
| **月度胜率**  | 正收益月份占比          | > 55%      | 低于 50% 说明靠少数月份撑         |
| **年换手**   | 双边成交额 / 2 / 平均净值 | < 10 倍     | 超过 20 倍，成本吃掉全部超额        |
| **IC 均值** | 因子分与下期收益的秩相关     | > 0.03     | 0.05 已很优秀；**0.01 就是噪声** |
| **ICIR**  | IC 均值 / IC 标准差   | > 0.5      | 衡量因子稳定性，比 IC 更重要        |

## 3. 真实数据跑出来的结果（2026-11-16）

```
多因子（80 只可选池，20 只持仓，2021-12 → 2026-11）
  年化 11.06% ｜ 基准 0.15% ｜ 超额 10.91%
  波动 27.0%   ｜ 回撤 -28.6% ｜ 夏普 0.41
  IC 0.022     ｜ ICIR 0.14  ｜ 年换手 3.1 倍

电网设备轮动（平高/思源/特变 三只）
  rotation     年化 25.89% ｜ 回撤 -32.1% ｜ 夏普 0.88
  sector_only  年化 16.60% ｜ 回撤 -41.4% ｜ 夏普 0.51
  当前信号：强度分 -0.20 → 回到全市场
```

**这三组数字的正确读法是：**

- **IC 0.022、ICIR 0.14 → 这个多因子模型基本无效。** 100 只样本里 IC 的标准误约 `1/√100 = 0.10`，0.022 完全落在噪声范围内。11% 的年化里有很大一部分来自"抽到的这 100 只恰好不错"，不来自因子。
- **轮动 25.89% 不能信。** 3 只股票、60 个月、1 个阈值，参数自由度为 0 的检验都做不了。夏普 0.88 不等于策略有效，等于"样本太小"。
- **可以信的只有一件事：存活偏差 0.57 个百分点/年。** 这是从 228 只退市股反推出来的，方向明确、量级可信。

## 4. 存活偏差到底有多少

`run_real.py` 的第 ⑥ 步会打印：

```
样本中 36 只是区间内才上市的（2021 年的池子里本不该有它们）
区间暂停/终止上市 228 只 / 现存 5579 只 → 退出率 3.93%
按退市前相对跌幅 85% 估算，等权基准年化虚高约 0.57 个百分点
```

三个必须理解的细节：

1. **样本里 100% 是活到今天的股票。** 上面 36 只 2021 年之后才上市的，等于在 2021 年的选股池里凭空多出 36 个"事后知道是好公司"的选项，这是**前视偏差 + 存活偏差**的叠加。
2. **0.57pp/年 是下限，不是上限。** 因为：(a) 退市统计用的是"暂停上市"口径，可能漏掉真正的终止上市；(b) 退市股在退市前通常已经跌了 90%+，且集中在**小市值**，如果你的策略有中小盘暴露，偏差会放大到 2–4pp/年。
3. **等权基准被高估得最厉害**，因为退市股在等权里权重恒定；市值加权基准受影响小。

**结论：免费数据能跑通流程，不能用来验证策略。** 想认真做，必须买含退市股的数据（Wind / 聚源 / 米筐 / 聚宽）。

## 5. 电网设备行业轮动因子怎么做的

`src/sector.py`，核心就三行：

```
RS(t, w) = 板块等权指数近 w 日收益 - 全市场等权近 w 日收益
score(t) = 0.5 × z(RS20) + 0.5 × z(RS60)
score > 0 → 持有板块三只；否则 → 回到全市场多因子组合
```

设计上刻意避开两件事：

- **不用绝对收益判断强弱。** 板块涨 20% 但市场涨 30%，是走弱，不是走强。所以用相对强度。
- **不用未来数据做 z 分数。** `expanding(120)` 滚动标准化，只用到当日为止的分布。

**它回答的问题不是"电网好不好"，而是"电网相对全市场，是在扩散还是收敛"。** 前者是观点，后者是数据。

想改成员：`sector.GRID_MEMBERS = ["600312","002028","600089"]`。  
想改阈值：`rotation_selector(..., threshold=0.3)` 更保守，只在强信号时切板块。

## 6. 接自己的数据

`data/prices.csv`（长表，7 列必需）：

| date       | code   | open  | close | limit_up | limit_down | suspended | volume  |
| ---------- | ------ | ----- | ----- | -------- | ---------- | --------- | ------- |
| 2026-01-05 | 600312 | 21.80 | 22.00 | 24.20    | 19.80      | false     | 8123400 |

`data/fundamentals.csv`：

| date       | code   | pe_ttm | pb  | roe_ttm | net_profit_yoy |
| ---------- | ------ | ------ | --- | ------- | -------------- |
| 2026-04-28 | 600312 | 21.8   | 2.1 | 11.2    | 25.3           |

**`date` 必须是这份信息真实可得的日期（公告日），不是报告期末。** 用 2026-03-31 的财报在 3 月 31 日交易，等于偷看 1–2 个月后的事。

## 7. 报错对照表（都是踩过的）

| 报错                         | 原因                  | 解法                                                   |
| -------------------------- | ------------------- | ---------------------------------------------------- |
| `stock_zh_a_hist 已更名`      | akshare 频繁改接口名      | 用 `stock_zh_a_hist_em`（东财）或 `stock_zh_a_hist_tx`（腾讯） |
| `Push2RateLimitError`      | 东财 IP 限流，5–40 分钟    | 换腾讯源，或降频、加 sleep                                     |
| `stock_a_indicator_lg 不存在` | 乐咕估值接口下线            | 改用 `stock_zh_valuation_baidu`                        |
| `ProxyError: www.bse.cn`   | 北交所域名不通             | 用缓存的股票列表（本仓库已内置回退）                                   |
| 回测一条成交都没有                  | 初始资金太小，买不起一手（100 股） | `Config(capital=1_000_000)`                          |
| 换手率几百万倍                    | 资金归一化后没还原分母         | 已修：`traded / capital`                                |
| 最大回撤 -100%                 | 用了未复权价或没处理停牌        | 检查 `adjust="qfq"` 与 `suspended`                      |

## 8. 从"能跑"到"能用"还差什么

- [ ] 数据换成含退市股的全样本（最大的一步）
- [ ] 因子加上质量与成长（需财报，按公告日对齐）
- [ ] 行业中性 + 市值中性（否则你的"超额"可能只是小盘 beta）
- [ ] 样本外：前 70% 调参，后 30% 只跑一次
- [ ] 模拟盘 3 个月，比对回测与实际的滑点差
- [ ] 写下**停止条件**（回撤超过 X% / IC 连续 N 月为负 → 自动降仓）
